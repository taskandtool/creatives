# campaigns/

One folder per campaign, `campaigns/<slug>/`:

```
brief.md      the agreed brief (briefs/_template.md; the `brief` skill)
angles.md     the angles and the 3×3 starter set (the `angles` skill)
claims.md     every claim the campaign may make, numbered, each with its source note
results.md    what ran, for how long, the numbers, what was learned (the `results` skill)
```

`campaigns/CURRENT` holds the slug of the campaign in hand (one line). The
creatives themselves live under `creatives/<status>/` and name their
campaign in `creative.md`.
